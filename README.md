# Galgame Studio · 视觉小说制作器

基于原项目「VN 模式」界面复刻的**带后端的 Galgame（视觉小说）制作器**。

## 账号系统

- **邮箱注册**：输入邮箱 → 收验证码（163 SMTP，10 分钟有效）→ 设密码，注册即登录
- **数据隔离**：登录用户的作品挂在账号下，其他人（无论游客还是别的账号）都看不到
- **游客模式**：未登录也能用，作品只存本机浏览器 localStorage，不上传服务器
- **公开示例**：无归属的作品对所有人生效为「只读示例」，可一键复制成自己的
- **找回密码**：同验证码流程可重置密码

## 启动

```bash
pip install -r requirements.txt
cp .env.example .env       # 填入你的 SMTP 信息（用于发送注册验证码）
python3 server.py          # 默认 0.0.0.0:3000，可用 PORT 环境变量修改
```

打开 http://localhost:3000 即可使用。

> SMTP 未配置时，注册验证码功能会提示 503，其余功能（游客模式、编辑、试玩、导出）不受影响。

## 功能

- **作品库**：新建 / 复制 / 删除作品，封面展示，云端自动保存（SQLite）
- **剧本编辑器**：
  - 场景管理（开场场景标记、跨场景清理引用）
  - 7 类节点：台词 / 旁白 / 选项分支 / 背景切换 / BGM / 跳转 / 结局
  - 节点排序、复制、内联编辑
- **角色管理**：名字颜色、站位（左/中/右）、头像、按 12 种情绪绑定立绘
- **素材上传**：图片 / 音频上传到服务器 `data/uploads/`
- **作品设置**：封面、简介、默认皮肤、打字速度、背景压暗、氛围光
- **试玩播放器**（复刻 VN 舞台）：
  - 双层背景交叉淡入 + Ken Burns 缓慢推移
  - 12 种情绪氛围光（背景随台词情绪染色）
  - 打字机 4 档速度 + 长句自动分页（实测宽度切页）
  - 选项分支（数字键直选）、自动播放、回顾记录、进度存档（继续游戏）
  - 4 套皮肤：经典 / 毛玻璃 / 极简 / 纸张；纯观赏模式（H）
- **独立 HTML 导出**：单文件播放器，发给别人双击即玩

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/projects` | 列表 / 新建 |
| GET/PUT/DELETE | `/api/projects/{id}` | 读取 / 保存 / 删除 |
| POST | `/api/projects/{id}/duplicate` | 复制 |
| GET | `/api/projects/{id}/export` | 导出独立 HTML |
| POST | `/api/upload` | 上传素材 |

## 数据结构（剧本）

- 场景 `scenes[]`：`{id, name, bg, bgm, nodes[]}`
- 节点：`dialogue`(speaker/emotion/text) · `narration` · `choice`(options[].goto→场景) · `bg` · `bgm` · `jump` · `end`
- 角色 `characters[]`：`{id, name, color, avatar, position, sprites{情绪→立绘}}`

## 已知限制

- 导出的独立 HTML 中素材为服务器绝对 URL（在线播放）；未做离线内联
- 单文件 SQLite，适合个人 / 小团队使用
